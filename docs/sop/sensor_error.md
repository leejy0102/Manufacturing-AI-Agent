# Sensor Error SOP

## 문서 목적
Sensor 오류 발생 시 감지 이상 원인을 확인하고, 생산 흐름을 안전하게 복구하기 위한 기본 대응 절차를 정의한다.

## 문제 정의
Sensor Error는 설비 또는 이송 구간의 Sensor가 제품, 용기, 위치 상태를 정상적으로 감지하지 못해 오동작, 정지 또는 인터록이 발생하는 현상이다.

## 주요 증상
- 제품이 존재하지만 Sensor가 감지하지 못함
- 제품이 없는데 Sensor가 지속적으로 감지 상태를 유지함
- 반복적인 Interlock 또는 Alarm 발생
- Conveyor 또는 설비의 비정상 정지
- 설비 동작 타이밍 불일치

## 가능한 원인
- Sensor 오염
- Sensor 위치 이탈 또는 정렬 불량
- 배선 접촉 불량
- Sensor 자체 고장
- 제품 간격 또는 위치 이상
- 반사광, 수분, 이물 등 주변 환경 영향

## 확인 절차
1. Alarm 또는 Interlock이 발생한 Sensor 위치를 확인한다.
2. Sensor 표면의 오염 여부를 확인한다.
3. Sensor 정렬 상태와 감지 거리를 확인한다.
4. 제품이 정상 위치를 통과하는지 확인한다.
5. 배선 및 커넥터의 이상 여부를 확인한다.
6. Sensor 표시등 또는 상태 신호를 통해 정상 감지 여부를 확인한다.

## 조치 절차
1. 현장 안전 절차에 따라 설비를 안전 상태로 전환한다.
2. Sensor 표면의 오염이나 이물을 제거한다.
3. Sensor 위치와 감지 방향을 조정한다.
4. 배선 및 커넥터 상태를 점검한다.
5. 제품을 수동으로 통과시켜 감지 여부를 확인한다.
6. 이상이 지속되면 Sensor 교체 또는 정비를 요청한다.
7. 정상 감지가 확인되면 설비를 재가동한다.

## 재발 방지
- Sensor 오염 상태를 정기적으로 점검한다.
- 진동에 의해 위치가 변하지 않도록 고정 상태를 확인한다.
- 반복 오류 Sensor의 발생 이력을 기록한다.
- 배선 및 커넥터의 손상 여부를 예방점검 항목에 포함한다.
- 동일 Sensor 오류가 반복될 경우 교체 주기 또는 설비 조건을 재검토한다.

## 주의사항
- Sensor 점검 및 조정 전 반드시 현장 안전 절차를 준수한다.
- Sensor 감도를 임의로 과도하게 변경하지 않는다.
- 실제 작업 시에는 해당 사업장의 공식 SOP와 안전 기준을 우선 적용한다.
- 본 문서는 포트폴리오용 가상 제조 시나리오를 기준으로 작성되었다.
