# Operator Adjustment SOP

## 문서 목적
생산 중 작업자의 수동 조정이 반복적으로 발생하여 정지 또는 속도 저하가 발생하는 경우, 원인을 확인하고 표준화된 방식으로 대응하기 위한 기본 절차를 정의한다.

## 문제 정의
Operator Adjustment는 설비 또는 제품 흐름을 유지하기 위해 작업자가 수동으로 위치, 가이드, 속도, 투입 상태 등을 반복적으로 조정하는 현상이다.

## 주요 증상
- 작업자의 반복적인 수동 개입
- 짧은 정지 또는 속도 저하 반복
- 특정 제품 생산 시 조정 빈도 증가
- 가이드, 센서, Conveyor 상태를 자주 수정
- 자동운전 상태가 안정적으로 유지되지 않음

## 가능한 원인
- 제품 규격 변경에 따른 설비 세팅 불일치
- 가이드 위치 또는 간격 부적정
- 제품 공급 상태 불균형
- Sensor 감지 위치 이상
- Conveyor 또는 설비 간 속도 불균형
- 표준 작업조건 미정립

## 확인 절차
1. 작업자가 반복적으로 조정하는 위치와 항목을 확인한다.
2. 특정 제품 또는 SKU에서 발생 빈도가 높은지 확인한다.
3. 설비 세팅값과 표준 조건을 비교한다.
4. 가이드, Sensor, Conveyor 상태를 점검한다.
5. 전후 공정의 제품 흐름과 속도를 확인한다.
6. 동일한 조정이 반복적으로 발생하는지 기록한다.

## 조치 절차
1. 반복 조정이 발생하는 위치와 원인을 확인한다.
2. 표준 세팅값과 현재 설비 조건을 비교한다.
3. 가이드, Sensor 위치, Conveyor 속도 등 필요한 항목을 조정한다.
4. 저속 운전으로 제품 흐름을 확인한다.
5. 정상 상태가 확인되면 표준 운전속도로 복귀한다.
6. 조정 내용과 결과를 기록한다.

## 재발 방지
- 반복 조정 항목을 표준작업서 또는 체크리스트에 반영한다.
- 제품별 주요 세팅값을 표준화한다.
- 동일 조정이 반복되는 설비는 개선 대상 항목으로 관리한다.
- 작업자별 경험에 의존하지 않도록 표준 조건을 명확히 관리한다.
- 조정 발생 빈도와 소요시간을 지속적으로 모니터링한다.

## 주의사항
- 설비 조정 시 현장 안전 절차를 우선 준수한다.
- 작업자의 경험만으로 세팅값을 임의 변경하지 않는다.
- 반복 조정이 지속되면 설비 또는 공정 조건의 근본 원인을 점검한다.
- 실제 작업 시에는 해당 사업장의 공식 SOP와 안전 기준을 우선 적용한다.
- 본 문서는 포트폴리오용 가상 제조 시나리오를 기준으로 작성되었다.
